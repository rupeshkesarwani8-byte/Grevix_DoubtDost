# DoubtDost

Student kisi bhi question ki photo upload karta hai, aur AI step-by-step Hinglish me samjhata hai,
galti kahan ho sakti hai uska hint deta hai, aur 3 milte-julte practice questions banata hai.

## Problem
Bahut se students ko raat ya exam ke time par doubt solve karne ke liye koi nahi milta.

## Stack
React (Vite), FastAPI, Gemini API
